### HW04 — JS 基礎 10 題

- **資料夾**：[`HOMEWORK/`](https://github.com/mahiruzzr/_wp1/tree/8f92150906be64b863c5214cd40039030ef26ca7/HOMEWORK)

| 4 | 購物車總額計算 | price × quantity 累加 |
| 5 | 倒數計時器 | while 遞減輸出 |
| 6 | 找出陣列最大值 | for + if 線性掃描 |
| 7 | JSON 轉換練習 | JSON.stringify / parse |
| 8 | 動態打招呼機器人 | Date().getHours() 分時段 |
| 9 | 陣列元素搜尋 | Linear Search 回傳索引 |
| 10 | 資料庫模擬 | 物件組合 + push + 排版輸出 |
